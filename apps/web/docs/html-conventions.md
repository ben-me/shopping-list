# HTML Conventions

- Use semantic HTML elements instead of generic ones that have a roles assigned.
- Semantic html elements are also better for accessibility since they don't need as many ARIA attributes (they already inherit correct ones)
- use generic <span> only for text styling if nessecary. Don't use throw them in wherever there's a line break or a separator
- divs are used only if there are no better fitting specific elements of for layout.
